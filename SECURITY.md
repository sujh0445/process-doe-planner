# Security And Safety

AI DOE Planner is a decision-support tool for experiment planning. It does not
control equipment, validate a production recipe, or replace engineer approval.

## Reporting A Security Issue

Do not open a public issue containing credentials, proprietary process data,
equipment access details, or unreleased manufacturing information. Contact the
repository owner privately through the contact method listed on the GitHub
profile.

## Data Handling

- Use synthetic, anonymized, or explicitly approved data in public examples.
- Keep raw training materials, production data, transcripts, and local output
  files outside version control.
- Review generated reports before sharing them because mechanism notes and
  measurement descriptions may contain sensitive process context.

## Operational Boundary

Every DOE recommendation must be reviewed against the actual equipment manual,
approved process window, measurement-system capability, and site safety rules
before execution.
